The build coverage page at `/builds/{id}/coverage` shows the code coverage report generated for a build.

## Using the page

- Review **Overall coverage** and **Changed coverage**, plus covered, executable, and uncovered line counts.
- Search and sort **coverage of changed files** and all coverage files by target, file, or path.

## Notes

- Generate the coverage report from the [Build details](/builds/build-detail) page first.
