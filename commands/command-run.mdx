The command run page at `/commands/runs/{id}` shows a single run's live terminal output and history.

## Using the page

- Watch **Terminal output** live — follow output, search, or view the raw log.
- Review **Attempts**, **Timing**, and the immutable **command snapshot**.
- **Rerun** the command or **Terminate** an active run.

## Notes

- Restart attempts that run for at least one minute reset the burst counter before their next exit is evaluated.
