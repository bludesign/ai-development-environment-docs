The **Commands** page at `/commands` lets you save reusable shell commands and review their durable run history.

## Using the page

- Switch between the **Runs** and **Definitions** tabs.
- **New command** saves a reusable definition; **Run custom** executes a one-off script without saving it.
- Choose where a command runs — an agent home or a repository worktree.
- Manage runs: **Archive**, **Restore**, **Delete**, **Rerun**, or **Terminate**.

## Notes

- Commands run with the full permissions of the selected agent account and are retained in immutable run history.
- Interactive input and PTY applications are not supported.
