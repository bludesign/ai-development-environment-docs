The **Actions Cache** page at `/actions-cache` browses and manages entries on a connected GitHub Actions Cache Server.

## Using the page

- Filter cache **entries** by key, version, scope, or repository, and open an entry for its **storage location**.
- **Match** the entry the server would restore for a set of primary and restore keys.
- **Delete** matching, selected, or individual entries and their storage locations.

## Notes

- Requires the Actions Cache Server to be configured in Settings; otherwise this page is hidden.
