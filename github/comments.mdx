The **Comments** page at `/comments` reviews and responds to GitHub review threads across your open pull requests.

## Using the page

- Select a pull request and filter review threads by unresolved state and author.
- **Reply** with Markdown, **Resolve**, or **Reopen** threads, and open them in GitHub.
- Switch between card and table layouts.

## Notes

- Requires a GitHub token with pull-request read and write access.
- GitHub controls whether your account can reply to a given thread.
