The **GitHub Cache** page at `/github-cache` inspects cached GitHub GraphQL reads and shows API usage, latency, point costs, and rate limits.

## Using the page

- Set the global **Cache TTL** and add **Custom GraphQL TTLs** for exact operation names.
- Review **rate limits** (GraphQL and REST), **API operations**, calls by source, and recent calls.
- Inspect **cached entries**, then **Force refresh**, **Delete**, or **Clear cache**.

## Notes

- TTL controls cache freshness, not how often a page polls GitHub.
- Overrides apply across authentication modes, request sources, and variables.
