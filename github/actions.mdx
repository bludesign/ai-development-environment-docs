The **GitHub Actions** page at `/actions` monitors workflow runs across your registered GitHub codebases.

## Using the page

- Filter by **repository**, **branch**, and **pipeline**, then expand a run to see its jobs and steps.
- **Retry**, **Cancel**, or **Force cancel** runs, and open a run or its worktree.
- Configure **Auto Retry** rules to automatically rerun selected workflows or jobs.

## Notes

- Requires a GitHub personal access token with Actions read access.
- Retrying a workflow run requires a verified GitHub App configured in Settings.
