The cached GraphQL entry page at `/github-cache/entries/{id}` shows a single cached GitHub GraphQL response in full.

## Using the page

- Inspect the cached **query**, **variables**, and **response data**, plus its authentication mode and freshness.
- **Force refresh** the entry or **Delete from cache**.

## Notes

- Entries are separated by authentication mode and variables, and show the last exact point cost.
