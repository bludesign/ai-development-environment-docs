The **Pull Requests** page at `/pull-requests` reviews your GitHub pull requests and monitored repositories together, with pipeline and approval status.

## Using the page

- Switch between the **Mine**, **Review requests**, and **Repositories** tabs, and filter by state or repository.
- Review each pull request's **Pipeline** and **Approval** status and open comments.
- **Merge** a pull request (squash, merge commit, or rebase) with commit message and email options.
- **Manage** monitored repositories and how Jira keys are parsed from pull request titles.

## Notes

- Requires a GitHub personal access token in Settings with pull-request read and write access.
- GitHub search returns at most 1,000 results.
