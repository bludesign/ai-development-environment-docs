The **Polling** page at `/polling` inspects the background operations that keep the control plane and agents in sync.

## Using the page

- Review **Server operations** and **Agent operations** with their **status**, **cadence**, last started and completed times, and next poll.

## Notes

- This page is read-only diagnostics — operation cadence is configured on the relevant settings and agent pages.
- Operations include codebase scan, Git fetch, agent heartbeat, job reconciliation, and GitHub notifications and auto-retry.
