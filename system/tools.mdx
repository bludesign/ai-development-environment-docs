The **Tools** page at `/tools` discovers, configures, and runs built-in and external MCP tools.

## Using the page

- Browse the **Tool catalog**, expand a tool, enter its parameters, and **Run** it to inspect the response.
- Add and manage **External MCP servers** over Streamable HTTP or legacy SSE.
- **Connect external clients** using the server URL and configuration, and review the **Audit** tab.

## Notes

- Write and destructive tools prompt for confirmation before running.
- Saved custom header values stay server-side and are never returned to the browser. The MCP endpoint is `/api/mcp`.
