The **Unified View** page at `/unified-events` combines console logs and analytics events into a single live timeline.

## Using the page

- Filter by collection — **All**, **Console**, or **Analytics** — and search across both.
- Add timeline **separators**, manage columns, and **export** rows.

## Notes

- This view shares filters, columns, and ingestion settings with the other observability pages.
