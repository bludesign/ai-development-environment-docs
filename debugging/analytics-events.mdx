The **Analytics Events** page at `/analytics-events` inspects product analytics events and their parameters live as they arrive.

## Using the page

- Search and filter events; add parameter **columns** to the table.
- Save reusable filters and column presets, and **export** matching rows.

## Notes

- Analytics events use the same ingestion and settings model as [Console Logs](/debugging/console-logs).
