The **Console Logs** page at `/console-logs` inspects searchable console output collected from builds and devices.

## Using the page

- Search output with **text**, **glob**, or **regex** modes, and apply **advanced filters**.
- Manage **columns**, add timeline **separators**, and **export** selected or matching rows.
- Open **Settings → API help** for the REST ingestion contract.

## Notes

- Console logs are sent to the app through a REST endpoint documented on the page's API help.
