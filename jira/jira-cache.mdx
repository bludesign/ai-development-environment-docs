The **Jira Cache** page at `/jira-cache` inspects cached Jira data along with API usage, latency, and errors.

## Using the page

- Set the **Cache TTL**, and review **API operations** and **recent calls** for each rolling window.
- Inspect **cached tickets** and their coverage and freshness.
- **Refresh** or **Delete** a ticket, or **Clear cache**.

## Notes

- Clearing the cache keeps API call history but removes cached responses and tickets.
