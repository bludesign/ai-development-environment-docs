The **Jira Tickets** page at `/jira/tickets` browses saved Jira projects and their sources — JQL queries and board URLs — grouped by status.

## Using the page

- Browse tickets by **project** and **source** in a board or table layout.
- **Manage** projects and sources, display settings, and branch naming for each project.
- **Create worktree** from a ticket, either as a new worktree or by switching an existing one to the ticket branch.

## Notes

- Requires Jira to be configured in Settings.
- A source with more than 1,000 tickets must be refined to see the remaining results.
