The workflow run page at `/workflows/runs/{id}` shows a single run's live graph, timeline, and step history.

## Using the page

- Watch the **Live run graph** and the **Timeline** of events, step attempts, session data, and resources.
- **Pause**, **Resume**, or **Cancel** the run.
- Answer a step's question inline when the run is waiting for input.
- **Repair blocked session data** with an atomic JSON merge patch, or **Replay and rewind** from a selected step.

## Notes

- A replay creates a new append-only generation; external effects are retained and not reversed.
