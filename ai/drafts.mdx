The **Drafts** page at `/drafts` holds saved prompts you can start later as a Plan or a Session.

## Using the page

- **New draft** saves a prompt for later; search existing drafts.
- Start a draft as a **Plan** or a **Session**, edit it, or delete it.

## Notes

- Drafts are a convenient staging area before committing a worktree and model to a run.
