The **Sessions** page at `/sessions` lists managed provider Sessions that run against a worktree.

## Using the page

- **New Session** starts a managed run against a selected worktree.
- Search and filter Sessions, and open one for its live transcript.

## Notes

- Sessions run without approval prompts and with unrestricted access while holding an exclusive worktree lease.
