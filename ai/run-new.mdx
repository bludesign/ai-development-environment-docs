The new run page at `/runs/new` starts a managed Plan or Session against a worktree.

## Using the page

- Choose a **worktree**, a **model** and effort, and whether to start a **Plan** or a **Session**.
- Enter the **prompt**, attach files, and select **MCP tool presets** to grant least-privilege built-in tools.
- **Start** the run, or **Save draft** to run it later.

## Notes

- No MCP tool presets are selected by default — grant only the tools the run needs.
- Attachments are limited to 25 MB per file and 100 MB total.
