The Plan details page at `/plans/{id}` shows a single Plan's transcript, linked items, and estimated cost.

## Using the page

- Review the Plan's **Activity**, **Linked items**, and estimated **usage and cost**.
- Answer questions, **Steer** the agent, or start a **Follow Up** (resume, fresh, or resend context).
- **Run Plan** to start an implementation Session from it, and **Export** as JSON or Markdown.

## Notes

- Plans share the same run interface as [Sessions](/ai/session-detail).
