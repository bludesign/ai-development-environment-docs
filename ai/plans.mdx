The **Plans** page at `/plans` lists read-only AI Plans that survey a worktree and propose work without modifying it.

## Using the page

- **New Plan** starts a read-only run against a selected worktree.
- Search and filter Plans, and open one to view its activity and proposed work.
- **Run Plan** turns a completed Plan into an implementation Session.

## Notes

- Plans are read-only — the app warns if a Plan unexpectedly changes the selected worktree.
