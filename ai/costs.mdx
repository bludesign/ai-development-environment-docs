The **Costs** page at `/costs` manages the model price catalog used to estimate the cost of Plans and Sessions.

## Using the page

- Set a custom **Model cost URL**, or **Use default** to use the built-in catalog.
- **Fetch latest** prices on demand.
- Search the **Model prices** table for per-million-token input, output, and cache prices and context windows.

## Notes

- Prices refresh automatically once a day; a failed fetch is reported inline.
