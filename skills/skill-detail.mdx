The skill editor at `/skills/{id}` edits a single skill package — its metadata and all of its files.

## Using the page

- Edit skill **metadata** and every file in the package: add, replace, rename, download, or mark executable.
- Toggle **Sync globally** to include the skill in personal or global client synchronization.
- Assign **Skill groups**, then **Save skill** or **Delete** it.

## Notes

- Binary files must be downloaded or replaced to change their contents.
