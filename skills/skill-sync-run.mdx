The skill synchronization page at `/skills/sync/{id}` reconciles database, personal, and project skills across agents.

## Using the page

- Review **Agent sync status** and the **Proposed changes** for each participating agent.
- Resolve conflicts — use the database version, the client copy, or edit manually — then **Apply sync**.
- Use **Skip pending clients** to apply only the ready changes.

## Notes

- Manual conflict resolution lets you compare complete packages, including text, binary, and executable files.
