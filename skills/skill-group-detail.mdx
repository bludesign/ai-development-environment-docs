The skill group details page at `/skills/groups/{id}` manages a single group's skills, repositories, and deployment.

## Using the page

- Manage **Skills in this group** and the **Repositories using this group**.
- **Sync group** to reconcile assigned repositories, then **Save group** or **Delete** it.

## Notes

- Deleting a group removes copies that are no longer required by another group.
